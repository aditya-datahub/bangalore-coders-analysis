# 🧑‍💻 Bangalore Coders: From Messy Text to Clean Data

> Every dataset starts messy. This project is about taming the chaos.

Bangalore is India's tech capital, and this project digs into data about the developers who power it. The catch? The raw data arrived as a jumble of **unstructured text**. Using Python and Pandas, I turned it into a **clean, analysis-ready dataset**.

**The goal:** show hands-on data cleaning and handling skills, the everyday bread and butter of a Data Analyst.

## 🔍 How It Works

1. **Parse**: extract structured fields from raw, free-form text
2. **Clean**: fix inconsistent and noisy values
3. **Standardize**: bring every record into a uniform format
4. **Validate**: check data quality after transformation
5. **Export**: save the final dataset as a CSV for analysis
